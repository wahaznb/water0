5. Accuracy & limits — read before quoting

  • Coaching lift is simulated. Responsiveness is assumed, not measured — the +14 to +48pp range is the honest result, not a point estimate.
  • No fatigue / habituation. Real users tune out ~5 nudges/day; the sim doesn't model that.
  • Simulated users drink like the generator. The control arm matching the generator's band is consistency, not validation.
  • Model metrics are from 2026-09-22. TensorFlow can't run on Python 3.14, so Keras retraining didn't re-run; recorded numbers stand.
  • Latency is desktop CPU. Phone silicon differs; the net is 7.8 KB so it won't matter.
  • Personal retrain needs ~100 logged days. Current user: 3 — not yet, by the README's own rule.
